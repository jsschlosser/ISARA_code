Welcome to ISARA’s documentation!

In Situ Aerosol Retrieval Algorithm (ISARA) is an open-source Python codebase that retrieves aerosol particle refractive index and hygroscopicity using user-inputted field campaign instrument data sets. This code relies on SIR SCA for look-up tables and SizeDistMerge for size distribution interpolation [1,2].

[1] Chemyakin E, Stamnes S, Burton SP, Liu X, Hostetler C, Ferrare R, Cairns B and Dubovik O (2021) Improved Lorenz-Mie Look-Up Table for Lidar and Polarimeter Retrievals. Front. Remote Sens. 2:711106. doi: 10.3389/frsen.2021.711106 [2] Bo Chen. bochens/SizeDistMerge: V0.5.0. Version v0.5.0, Zenodo, 15 June 2026, https://doi.org/10.5281/zenodo.20709064.

We hope that the community uses this software to streamline verification of field aerosol data sets and ultimately advance field campaign data quality assurance. More information on this software including installation and use can be found in this “User Guide”.
